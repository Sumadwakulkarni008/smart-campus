# Smart Campus Rescue — GitHub Pages Version

This is a free, static HTML/CSS/JavaScript prototype of the Smart Campus Rescue LCNC case study.

## Files
- `index.html` — app structure
- `style.css` — responsive mobile/desktop design
- `script.js` — demo data, navigation, attendance updates, alerts and analytics

## Run locally
Just double-click `index.html`, or open it in VS Code and use Live Server.

## Deploy on GitHub Pages
1. Create a GitHub repository, for example `smart-campus-rescue`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you a public URL.

The app uses fictional student data and is intended as a college case-study demonstration.
