How the system works

📱 Student

Logs in with USN and sees only their own attendance, history and notifications.

👨‍🏫 Teacher

Opens assigned class, marks Present/Absent and submits attendance.

🛡️ Admin

Creates student/teacher accounts and classes. Teachers and students cannot create users.

⚡ Automation

When a student is marked absent, an in-app notification is created automatically.

Message note: This version sends an in-app absence notification. Real SMS/WhatsApp delivery needs an external messaging provider.
